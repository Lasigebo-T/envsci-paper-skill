---

## 0. Hard caveat — read this first (and tell the user)

Journal **scope, word limits, impact factors (IF), and submission requirements drift every
year.** The tables below are an accurate *snapshot for orientation and triage* — they are
**not** a substitute for the journal's current **Guide for Authors / Author Information Pack**.

**Iron rule for this stage:** before you state a hard number to the user as final
(word count, abstract length, highlight count, TOC-graphic size, IF), say where it came
from and add: *"Verify against the current Guide for Authors before submission — limits and
scope are revised periodically."* Never invent a precise limit you are not sure of; give the
documented value with the snapshot caveat, or say it must be checked. Do **not** fabricate an
impact factor — IFs are published annually and move; quote them as **approximate, year-tagged,
verify-on-site** or omit.

This mirrors the project-wide anti-fabrication stance: a number you cannot stand behind is a
`[MATERIAL GAP]`, not a guess.

## 2. Per-journal hard limits & required components (snapshot — verify on site)

Use these to run the **Journal-fit gate** (word/abstract/highlights/graphic limits met +
correct citation style). Treat each value as a documented snapshot, not a guarantee.

### Elsevier journals (STOTEN, WR, EP, JHM, Chemosphere, Env. Research, Ecol. Indic., MPB, Atmos. Env., JEM)
- **First submission can be format-free** ("your paper, your way"): single file, readable, references present — exact style enforced only on revision/acceptance. Still respect word/abstract/highlight limits.
- **Reference style:** **numbered Vancouver `[n]`** (Elsevier numeric). One numbered list in citation order.
- **Highlights:** **3–5 bullet points, each ≤ 85 characters including spaces** (Elsevier-wide requirement for most of these titles).
- **Graphical abstract:** expected/required for most of these titles (single image; check the title's exact spec — typically min ~531 × 1328 px or vector, ≥ 531 px shortest side).
- **Word counts (snapshot, verify):** STOTEN guide ≈ **≤ 8,000** words; MPB research articles ≈ **6,000**; others often **not a single hard cap** but expect concision — read the title's Guide for Authors.
- **Structured abstract:** **STOTEN uses a structured abstract ≤ 300 words.** Most other Elsevier env titles use an unstructured abstract (~200–250 words) — confirm per title.

### ACS — Environmental Science & Technology (ES&T)
- **Word-equivalent budget** ≈ **≤ 7,000 word-equivalents** for a full Article; **figures and tables consume the budget** (each counts as a word-equivalent block — confirm the current conversion on the ACS page).
- **Reference style:** **ACS author-choice**, but **article titles and DOIs are required** in the reference list (do not strip titles).
- **TOC / abstract graphic:** required, **~3.25 in × 1.75 in (≈ 8.25 × 4.45 cm), ≥ 300 dpi.**
- **Synopsis:** a **~50–60-word** plain-language synopsis accompanies the TOC graphic.
- ES&T is **selective** — see §3 desk-reject logic.

### Springer — ESPR
- **Reference style:** **author–year (name–year)** by default (Springer Basic/SpringerLink style).
- Standard Springer front matter (structured or unstructured abstract per current instructions; keywords). Graphical abstract optional.
- More receptive to regional monitoring + index/risk studies; a realistic home when novelty is solid-but-incremental.

> **All of the above are snapshots.** If you state any of these as the operative limit for the
> user's submission, append the verify-on-site caveat from §0.

## 3. Journal-fit decision workflow

Given a manuscript's **(a) topic/matrix, (b) novelty type, (c) scope/angle**, recommend
**2–3 candidate journals** ranked, each with a one-line fit rationale and the main desk-reject
risk. Use the safe-default discipline: when the study is a solid-but-incremental monitoring
survey, *do not* push the user toward a top flagship they will likely bounce off — name a
realistic primary and a credible reach/safety pair.

### Step 1 — Classify the manuscript on three axes

1. **Primary matrix / compartment**
   - Water/wastewater → WR (if process/mechanism), EP/STOTEN/ESPR (if quality/occurrence + risk)
   - Soil/sediment/sludge contamination → JHM, EP, STOTEN, ESPR, Ecol. Indic.
   - Marine/coastal/estuarine → **MPB** (+ STOTEN/EP if broader)
   - Atmosphere / aerosol / PM → **Atmospheric Environment** (+ STOTEN/EP)
   - Cross-compartment / whole-environment → **STOTEN**
   - Environment–health / exposure → **Environmental Research**, EP

2. **Novelty type** (what is the actual contribution?)
   - **Mechanism / process / conceptual advance** → ES&T, Water Research, JHM (top tier)
   - **Hazard / remediation of a hazardous substance** → **JHM**
   - **Occurrence + pollution-index + risk assessment of a region** (descriptive monitoring) → **ESPR, EP, STOTEN, Chemosphere, MPB/Atmos. Env.** (matrix-dependent) — **not** WR/ES&T
   - **New index / indicator / integrated monitoring framework** → **Ecological Indicators**
   - **Management / policy / decision intervention** → **Journal of Environmental Management**

3. **Scope/angle** — single-matrix vs integrated; local case study vs generalizable; pure
   occurrence vs effects/risk vs management. This axis decides flagship-vs-realistic.

### Step 2 — Desk-reject screen (apply BEFORE recommending)

A **CRITICAL fit warning** if any of these hold for a top-tier target:
- **Pure occurrence survey with no mechanism/process novelty → NOT Water Research or ES&T.** This is the most common mis-aim. Route to ESPR/EP/STOTEN/matrix-specialist instead.
- **No management/decision implication, but targeting JEM → weak fit.** JEM wants the "so-what for management."
- **Single matrix, no whole-environment integration, targeting STOTEN → weaker fit.** STOTEN rewards cross-compartment framing; a single-matrix study can still fit if framed within the total-environment context, but flag the risk.
- **Indicator/framework is the contribution but targeting a chemistry flagship → consider Ecological Indicators** where that *is* the expected contribution.
- **Recommending Chemosphere → flag the 2024 WoS delisting**; confirm current indexing status and whether the user's institution credits it.

### Step 3 — Emit 2–3 ranked candidates

For each candidate give: **journal · why it fits (one line) · main risk / what to strengthen ·
the operative format constraint (with verify caveat).** Always present a **primary**, a
**realistic alternative**, and (optionally) one **reach or safety**.

**Worked example A — "Heavy metals (Cd, Pb, As, Cu, Zn) in surface sediments of an estuary;
Igeo + enrichment factor + Hakanson RI + comparison to SQGs (TEL/PEL); autumn 2025 campaign;
no new mechanism."**
1. **Marine Pollution Bulletin** *(primary)* — matrix-exact (estuarine/marine sediment), receptive to occurrence + index + SQG-risk studies; risk: needs a clear contribution beyond "another contaminated site," ~6,000-word guide (verify).
2. **Environmental Pollution** *(realistic alternative)* — fits metal contamination + ecological-risk framing with broader readership; risk: stronger novelty/effects angle expected.
3. **ESPR** *(safety)* — broad-scope home for regional monitoring + index/risk; author–year style; most forgiving of incremental novelty.
   - **Not** Water Research / ES&T (no process/mechanism novelty → desk-reject risk).

**Worked example B — "New integrated water-quality index combining WQI with a biological
indicator, validated across 30 river sites."**
1. **Ecological Indicators** *(primary)* — the index/framework *is* the contribution; exactly this journal's remit.
2. **Journal of Environmental Management** *(alternative)* — if the paper foregrounds a monitoring/management decision use-case.
3. **STOTEN** *(reach)* — if the validation spans compartments and the whole-environment framing is genuine.

**Worked example C — "Mechanism of PFAS removal by a novel adsorbent, with isotherms,
kinetics, regeneration, and a real-wastewater test."**
1. **Water Research** *(primary)* — process/mechanism novelty in water treatment; its core remit.
2. **Journal of Hazardous Materials** *(alternative)* — PFAS = hazardous substance + removal focus.
3. **ES&T** *(reach)* — if the mechanistic/conceptual advance is strong and broadly significant; mind the ~7,000 word-equiv budget + TOC graphic.

### Step 4 — State the verify-on-site reminder

Close every recommendation with: *"Confirm the current scope, word/abstract/highlight limits,
graphical-abstract spec, and reference style on each journal's Guide for Authors before
submitting — these are revised periodically and the figures above are an orientation snapshot."*

## 4. How to read a journal's Guide for Authors (so the user can verify)

When the user needs the authoritative, current rules, walk them through (or do, if they paste
the page text as **data** — see SKILL.md untrusted-materials rule) this checklist:

1. **Scope / Aims & Scope** — does the journal explicitly list the study's matrix, contaminant
   class, and *angle* (occurrence vs mechanism vs management)? Look for "does not consider"
   exclusions (e.g. WR's stance on pure occurrence; STOTEN's whole-environment expectation).
2. **Article types** — pick the right one (Research Article vs Short Communication / Baseline /
   Letter). Limits differ by type.
3. **Word / length limit** — total word count, whether **abstract/references/captions count**,
   and (ES&T) whether **figures/tables consume a word-equivalent budget**.
4. **Abstract** — **structured vs unstructured**, and the word cap (e.g. STOTEN ≤ 300, structured).
5. **Highlights** — count and the **per-bullet character cap** (Elsevier: 3–5 × ≤ 85 char).
6. **Graphical abstract / TOC graphic** — required vs optional, exact **dimensions and dpi**
   (ES&T TOC ≈ 3.25 × 1.75 in, ≥ 300 dpi; Elsevier graphical-abstract pixel/vector spec).
7. **Reference style** — numbered Vancouver (Elsevier) vs author–year (Springer/ESPR) vs ACS
   (titles + DOIs required). Note "format-free first submission" if Elsevier.
8. **Required statements** — Data Availability, CRediT author contributions, Conflict of
   Interest, Funding, Ethics, **AI-use disclosure** (increasingly mandatory). Map these to the
   manuscript's existing statements; flag any missing as `AUTHOR_INPUT_NEEDED`.
9. **Figure/table technical specs** — file formats, min resolution (≥ 300 dpi raster /
   vector preferred), single-column ≈ 89 mm vs double ≈ 183 mm widths (see `envsci-figures` skill).
10. **Cover letter & suggested reviewers** — whether required; novelty/fit statement.
11. **Indexing sanity check** — confirm the journal is currently in the user's required index
    (WoS/Scopus) — **especially Chemosphere (delisted from WoS in 2024).**

**Triage rule:** verify items **1–7** before drafting/finalizing for a target; items **8–11**
before the actual submission click. Every number you transcribe from the page is now a verified
fact you may state without the snapshot caveat — but cite that you read it from the current
Guide for Authors.

## 5. Style takeaways (cheat-sheet)

- **Elsevier (STOTEN, WR, EP, JHM, Chemosphere, Env. Research, Ecol. Indic., MPB, Atmos. Env.,
  JEM):** numbered Vancouver `[n]`, **format-free first submission**, 3–5 highlights (≤ 85 char),
  graphical abstract expected.
- **ACS (ES&T):** ACS reference style with **titles + DOIs required**; word-equivalent budget;
  **TOC graphic (3.25 × 1.75 in, ≥ 300 dpi) + ~50–60-word synopsis**; selective.
- **Springer (ESPR):** **author–year** references; broad scope; realistic home for regional
  monitoring + index/risk studies.
- **Chemosphere:** flag **2024 WoS delisting** — confirm current indexing before recommending.
- **Universal:** never invent an IF or a limit; quote the snapshot with the verify-on-site
  caveat, or read it from the current Guide for Authors and cite that source.
